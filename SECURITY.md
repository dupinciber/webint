# Security Policy

## Responsible use

DUPIN WEBINT performs active reconnaissance (DNS, HTTP probing, fuzzing, vulnerability
templates, secret scanning). It must only be used against systems, domains and
assets that you own or have **explicit written authorization** to test.

Using DUPIN WEBINT against third parties without permission may be illegal. The
authors and DUPIN Ciberseguridad accept no liability for misuse.

## Reporting a vulnerability

If you find a security issue in DUPIN WEBINT itself (the code in this repository),
please report it privately through the contact form at:

**https://dupin.com.ar** → Contacto

Please do **not** open a public GitHub issue with sensitive details, proofs of
concept or affected third parties. Include:

- A clear description of the issue and its impact.
- Steps to reproduce (minimal proof of concept).
- Affected version or commit hash.

We will acknowledge the report and coordinate disclosure through the contact
channel you provide.

## Scope

This policy covers the DUPIN WEBINT source code distributed in this repository.
Issues found in third-party services used by DUPIN WEBINT (your AI provider, Shodan, Hunter.io,
public OSINT sources) should be reported to those providers.
